# 网站使用说明

## 当前状态

已创建首页、归档页、关于页和 404 页面，并准备好文章模板。
首页和归档页显示“暂无文章”；关于页只有标题，未填写个人资料。
没有创建任何文章，导航、日期、标签和页脚属于网站框架。

## 页面是怎样组成的

每个页面先选择一个模板，模板再套入共用的网页外壳：

```text
index.html ──────────────────────┐
about.md / archive.html → page ──┼→ default → 完整网页
_posts/ 中的文章 → post ─────────┘
```

`default.html` 负责共用结构，`page.html` 负责普通页面，`post.html` 负责文章。
`{{ content }}` 是模板中放入页面正文的位置。
`_includes/header.html` 和 `_includes/footer.html` 分别提供导航和页脚。

## 以后常改哪些地方

- 修改博客名称、作者和介绍：编辑 `_config.yml`。
- 修改顶部导航：编辑 `_includes/header.html`。
- 填写个人介绍：编辑 `about.md` 中第二个 `---` 下方的正文。
- 修改宽度、颜色、字体和间距：编辑 `assets/css/style.css`。
- 修改文章页结构：编辑 `_layouts/post.html`。
- 写文章：在 `_posts/` 新建 Markdown 文件，文件名使用 `年-月-日-英文短标题.md`。
- 放图片：放入 `assets/images/`，以后在文章中引用。

文章最上面的两条 `---` 之间填写标题、日期、摘要、标签等设置，下面写正文。
默认文章模板已在 `_config.yml` 中指定，首页和归档会自动更新。
归档按年份整理；标签当前只展示文字，不带筛选功能。

## 公式与代码

文章默认加载 MathJax 3，用于显示 LaTeX 数学公式。公式脚本来自 jsDelivr，首次加载需要联网。
不用公式的文章可以在开头的设置区写 `math: false`，关闭加载。
Markdown 解析器可能处理单个美元符号；行内公式建议使用 kramdown 的 `$$…$$` 写法。
独立公式使用上下单独一行的 `$$` 包围。
代码块使用 Markdown 的三个反引号，并标注语言，Jekyll 的 Rouge 会提供语法高亮。
后续添加第一篇文章时，再实际核对公式与代码渲染。

## 怎样预览和发布

这些是 Jekyll 源文件，直接双击 `index.html` 无法得到完整网站。

发布到现有 GitHub Pages 时，在仓库 Settings → Pages 中确认发布源为
Deploy from a branch，分支 `main`，目录 `/(root)`。提交并推送之后由 GitHub 构建。
Git 提交和推送负责上传源文件；GitHub Pages 设置决定上传后是否自动发布网站。

以后若需要本地 Jekyll 预览，先安装 Ruby 和 Bundler，然后在仓库目录运行：

```powershell
bundle install
bundle exec jekyll serve
```

打开终端输出的本地地址即可。修改 `_config.yml` 后需要重启预览服务。
当前没有要求安装这些工具，也不需要为了提交源文件先安装它们。

## 哪些东西不会被发布

`README.md`、`docs/`、`Gemfile`、`Gemfile.lock` 和 `vendor/` 已从网站输出中排除。
文档中的教学内容不会变成博客文章。
`_site/` 是 Jekyll 自动生成的结果，不需要手动编辑或提交。
